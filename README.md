# Mad Libs

Mad Libs is a command-line word game written in Python. The player chooses a
story template, enters words without seeing the story, and then receives a
funny completed story.

## Features

- Three story templates: hospital, camping, and enchanted castle
- An optional random template selection
- Input validation for menu choices and empty answers
- Repeated placeholders reuse the same player input

## Requirements

- Python 3
- No external packages are required

## How to Run

Open a terminal in the project directory and run:

```bash
python3 mad_libs.py
```

## How to Play

1. Choose one of the three story templates, or choose the random option.
2. Enter a word for every prompt.
3. Read the completed Mad Libs story.
